# 上传范围、来源与剩余缺口

## 应上传

PUBLIC_MANIFEST.json 列出的源码覆盖层、补丁、工具、测试、文档/PDF、来源清单、许可证和聚合证据。
README / PDF / 迭代文档都属于新公版文件，已纳入新的公开清单，不改历史验收清单。

## 不上传

build、reports、.venv、模型、CUDA 扩展、缓存、原始日志/响应、私有 ZIP、完整历史执行包、Git bundle 或其它上游副本。
ZIP 交付包不会包含这些生成目录。原始 Git、失败证据及实验成绩仍在原项目，未重置、改写或删除。

## Git 历史处理

远程运行目录未在两个检查位置发现 .git；本地工程有独立 Git 历史，保持原样。
本次公版是独立文件候选，未执行 git init、commit 或 push，也没有将含私有证据的旧历史直接迁移到新公开仓库。
使用者应 clone 目标仓库，然后增量复制白名单文件并审阅提交。目标已有历史会保留；冲突文件必须人工合并，不强制覆盖或 force push。
如果以后需要公开旧历史，必须先额外审查其中的日志、作者信息和二进制；不能只靠当前 .gitignore 处理过去提交。
